## 关于 GenPlay

GenPlay 是一个 **AI 原生的游戏创作与编辑平台**，一座覆盖游戏构建、编辑与发布的完整游乐场。在这里，游戏通过智能 Agent 真正地"活"起来。

在这里，AI 不是静态游戏上的外挂。GenPlay 让 **Agent 本身成为游戏的表达媒介**：每一个角色、每一条规则、每一个世界与交互，都源自 AI 原生行为并被其驱动。

它的核心信念只有一个：**游戏不是完成的成品，而是一场活着的对话。** 在 AI 原生的世界里，游玩不再是等待被遵循的一组固定规则，而是一场不断生长、回应并记住你的开放对话。

GenPlay 沿着两条交织的路径展开：

- **创作与编辑 AI 原生游戏** —— 从零塑造世界、角色与玩法机制，再通过 Agent 驱动的编辑实时重塑它们。
- **探索 AI 原生游戏** —— 深入只有 AI 原生世界才能承载的玩法、交互与游戏类型。

无论你是建造新世界的创作者，还是踏入世界的玩家，GenPlay 都让你在两种身份之间自由切换 —— 因为在 AI 原生游戏里，创造与游玩之间的界限正逐渐消融。

GenPlay 不止是一件工具，更是一座 **发明家的游乐场** —— 一个在 AI 时代重新思考"游戏是什么、我们该如何去玩"的地方。



## 创作与编辑：让 AI 原生游戏活起来

在 GenPlay，创作与编辑并非两个独立的步骤，而是一场由 Agent 全程引导、持续进行的创造行为。

- **Agent 优先的创作** —— Agent 是创作的核心，而非附属。角色实时推理、回应并与你共同创造，把模糊的想法变成具体可玩的世界。
- **对话式编辑** —— 直接与游戏对话即可重塑它。Agent 将你的意图转化为可玩内容，让你像聊天一样自然地调整规则、场景与角色。
- **实时共创** —— 你从不独自创作。Agent 作为共同设计者，与你一起提议、调整与打磨 —— 全程不停歇。
- **记住你的世界** —— AI 原生角色与场景会把过往的每一刻延续下去，让你的作品持续生长为一个鲜活的所在，每一次编辑都在前一次的基础上延伸。
- **从提示到生态** —— 平台本身即是画布。从一句想法起步，生长为鲜活而彼此联结的游戏世界 —— 以及其间的一切可能。



## 探索：AI 原生游戏的下一种形态

不止于创造，GenPlay 更是一座发现"游戏在 AI 时代还能成为什么"的起点，为"打破熟悉、发明未来"而生。

- **新玩法** —— 任何静态规则集都无法表达的游戏体验。Agent 生成、适应并演化玩法，甚至给创作者带来惊喜；规则本身也成为游玩的一部分。
- **新交互模式** —— 超越屏幕与手柄的游玩：对话式游玩、涌现式对白，以及把你当作"人"而非仅仅"玩家"来回应你的世界。
- **新游戏类型** —— 只存在于 AI 原生世界的品类：自行书写的故事、记住你的世界、永不复现的挑战。
- **新创作流程** —— 重新构想游戏的制造方式，从一句提示到一个鲜活的生态，打开传统流程从未触及的门。

在 GenPlay，你不受"游戏过去是什么"的束缚 —— 而是去定义"它们还能成为什么"。



## 快速开始

```bash
# 克隆仓库
git clone https://github.com/Yuan-ManX/GenPlay.git
cd GenPlay

# 安装依赖
npm install

# 启动开发环境
npm run dev
```
